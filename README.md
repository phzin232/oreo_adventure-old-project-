# **OREO ADVENTURES** (*Projeto Antigo - Unity*)


## Um projeto feito em cerca de 2021

quando eu estava entrando no mundo de programação, antes de dar uma pausa. Nesse o codigo inteiro vai estar no básico. Pois eu não sabia nem usar Git.

**Agradeço desde já por estar aqui**

Esse projeto nunca foi completado. Pois como eu disse foi antes da minha pausa por motivos pessoais, então vai ter muita coisa incompleta. Codigo com bugs, erros bobos, justamente por eu nunca ter nem se quer estudado POO. Mas vamos ao que interessa mesmo!

Features do jogo

- Troca de cenario
- Menu incial semi interativo
- Botões funcionais(as vezes demora um pouco pra ir)
- Loja
 - Compra de vida adicional e buff de moeda
- Inimigos
- Som de slime do minecraft nos inimigos (essencial)
- flecha some após 10 segundos
- double jump (funciona meio estranho)
- Sistema reinicio caso morra

Jogo feito em C# e originalmente usando o Devops da Unity.
